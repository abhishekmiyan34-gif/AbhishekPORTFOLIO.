01 // ABOUT MY JOURNEY

Learning by doing, experimenting with code, and exploring what excites me.

I am a B.Tech student currently in the early stages of my engineering education. I believe the best way to understand technology isn't just reading textbooks — it's sitting down, writing code, tinkering with hardware, making mistakes, and seeing how things work from the ground up.

My journey started with the basics of the web: semantic HTML, responsive CSS, and JavaScript. Along the way, I've been learning Data Structures & Algorithms using Python and C++, getting comfortable with the Linux terminal, and practicing Git for version control.

Beyond software, I'm genuinely curious about physical computing. I like tinkering with Arduino boards, wiring basic sensors, and seeing code interact with the physical world. That curiosity is what makes me excited about learning robotics, computer vision, and autonomous drone concepts like AeroKart in the future.

«I don't claim to be an expert in technologies I am still learning. What I care about is staying curious: every concept I study becomes code, every challenge teaches me something new, and every project helps me grow.»

05 // MY LEARNING PHILOSOPHY

“Build. Learn. Improve. Repeat.”

I believe the best way to grow is to stay curious and build things. I don't wait until I feel like an "expert" to start writing code — every new concept I learn, I try to turn into a small project or experiment.

When code doesn't work or an experiment fails, that's where the real learning happens. Each bug teaches me how computers actually think, and each challenge improves how I approach problems.

My story is: I'm learning. I'm building. I'm experimenting. I'm figuring out what I want to become.
