## 🎨 Design System

- **Theme**: Sophisticated light theme (soft off-white `#FAF9F6` background with subtle borders `#E5E7EB` and deep charcoal `#111827` typography).
- **Accent**: One restrained blue (`#2563EB`).
- **Typography**: `Inter` for clean reading + `JetBrains Mono` for code and status indicators.
- **Visuals**: Clean rectangular portrait frame with subtle coordinate marks, blueprint schematics, and restrained layout styling.
- **Motion**: Subtle scroll transitions via `IntersectionObserver` with full support for `prefers-reduced-motion`.

## 🚀 How to Run Locally

Because this project is built entirely on native web standards (**no Node.js build step or bundler required**):

### Option 1: Direct File Opening
Double-click `index.html` or open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Using Python Simple HTTP Server
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.

### Option 3: VS Code Live Server
Right-click `index.html` in VS Code and click **"Open with Live Server"**.
